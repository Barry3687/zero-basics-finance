# 零基礎個人投資與理財入門

給沒有股市、基金或財經先備知識的大學生與社會新鮮人。先整理生活中的錢，再理解計息、工具與風險，最後寫自己的計畫；沒有要求讀完就必須開始投資。

## 如何使用

每課依序讀定義、生活比喻、數字試算、誤區，先回答課末選擇題，再進入獨立練習檔看提示與解析。各課含數個基礎概念，但按先備順序逐一介紹；本階段是 Markdown 教材，沒有自動判分或進度鎖定功能。

## 來源與內容標示

- 【來源內容】：依可查資料轉述；重要主張旁以來源 ID 連結定位。
- 【教學轉譯】：為新手設計的說明或比喻，並列比喻限制。
- 【假設例子】：自行設定的數字與條件，不是歷史績效、現況數據或收益預測。
- 【自編練習】：本專案設計的題目，非來源機構原題。
- 【待確認】：尚未釐清的來源資訊；未驗證內容不得當已知事實。
