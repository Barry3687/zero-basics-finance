# 練習 05：面對催促匯款的訊息

【自編練習】陌生群組保證「每月高報酬、完全零風險」，並催你當天匯款。哪個做法較合適？

- A. 先匯小額就代表安全。
- B. 只看平台獲利截圖便匯款。
- C. 暫停匯款，另找官方管道查核，必要時洽 165。
- D. 提供銀行驗證碼讓對方代操作。

## 先想想

訊息有沒有聲稱不可能損失？驗證方式是否仍由同一個陌生群組提供？

## 提示

用與對方無關、自己查找到的官方管道查證；不要把看見畫面上的獲利當成資金安全證據。

## 答案與逐步解析

正確答案：**C**。

1. 高報酬卻聲稱零風險，是與正常風險概念不相符的警訊。
2. 催促立即付款會壓縮查證時間，應先停止匯款。
3. 自行找到官方機構或 165 管道查核；不單靠群組給的網址、電話或截圖。
4. 不交出帳密或驗證碼。此題辨識應採取的查核行動，不是替個別案件作法律定性。

## 其他選項錯在哪

- A：小額能領回也不能證明平台可靠。
- B：畫面或截圖可以被偽造，不能代替查證。
- D：驗證碼可涉及帳戶控制，不能交給陌生人操作。
